# Interactive Tech Repair Shop System

## Project Description
This project is a terminal-based management system for a tech repair shop developed using Python and Object-Oriented Programming (OOP) concepts.

The system allows users to:
- View available repair services
- Add repair services to a customer invoice
- View invoice details
- Print the final bill
- Exit the system safely

---

## OOP Concepts Used

### 1. Abstraction
Implemented using the abstract class:
- `RepairService`

### 2. Inheritance
Implemented through:
- `HardwareRepair`
- `SoftwareRepair`

### 3. Encapsulation
Sensitive data such as labor cost and repair status are protected using:
- Private variables
- Getters and setters

### 4. Polymorphism
Different repair types implement:
- `calculate_service_cost()`
in different ways.
